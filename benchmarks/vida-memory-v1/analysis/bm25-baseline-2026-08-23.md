Exact keyword retrieval, current-value filtering, entity isolation,
abstention, and source identity passed. Semantic paraphrase, Chinese-to-English
retrieval, and the punctuation-heavy historical model query failed. The
overall gate is therefore correctly blocked.

This result freezes the pre-hybrid comparator. It does not justify changing
the quality threshold or claiming that BM25 is sufficient; the next retrieval
variant must improve semantic recall without regressing stale-value filtering,
abstention, source identity, or latency.
